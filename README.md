# Draky Software — Identidad corporativa

Repositorio oficial de recursos gráficos de Draky Software.

## Diseño aprobado

**Draky Refinado**: dragón verde integrado en la letra D, marca «Draky» y subtítulo «Software».

## Colección prevista

- Icono cuadrado y logotipo horizontal.
- Color para fondos claros, fondos oscuros y fondo transparente.
- Blanco y negro para fondos claros, fondos oscuros y fondo transparente.
- PNG de 256, 512, 1024 y 2048 píxeles (48 imágenes).

**Estado actual:** los archivos gráficos todavía no se han subido al repositorio. Esta página documenta la colección, pero no sustituye a los archivos originales.

Las imágenes PNG grandes proceden de escalado rasterizado. No hay todavía un archivo SVG vectorial maestro validado.
